## Publish the update
1. Open the `Kubafaw/Kubafaw.github.io` repository on GitHub.
2. Back up or download the current repository contents.
3. Upload/replace `index.html`, `style.css` and `photo.jpg` in the repository root.
4. Commit the changes to the branch used by GitHub Pages (usually `main`).
5. Wait for GitHub Pages to rebuild, then check https://kubafaw.github.io/

The new PySide6 project card does not link to a separate repository because a repository URL for that project was not provided.
